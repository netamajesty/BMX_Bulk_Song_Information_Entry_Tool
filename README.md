# BMX_Bulk_Song_Information_Entry_Tool
A tool that allows for the batch input of everything from song details to timing settings for BMX (BMS, BME, BML, PMS) charts across various difficulty levels.

英語で書いてはいますが、このプログラムは日本語であり、AIと一緒に考えて作ってみました。

このプログラムは、譜面１つ１つの処理を少しでも緩和できるよう、製作者から見た視点で機能をモリモリ入れ込みました。

かくいう自分も曲の製作者側です。

Pythonですが、3.8.10のため、win7までサポートします。

外部ツールを使用していませんので、requirements.txtでEXE化も単体でできます。

使い方と機能について：
1. 下のレベル別譜面選択で適当に選んでもらうと、同じフォルダにあるBMSファイルが「各レベルの単語」を判断して自動で読み込んでくれます。
2. 上の空白にジャンル名、曲名、アーティスト名を入力する。
3. 判定(RANK)は0～3までの値しか許容できません。(初期値や空欄時は２が自動選択される仕組みです)
4. 管理番号は個人的に欲しかったので入れていますが、不要であればチェックを外して空欄でOKです。
5. レベル別譜面の各欄にレベルを入力できます。(0～99まで数字のみ適用されます)
6. 入力が確認出来たら一括書き込みを実行ボタンで書き込みます。(ほぼ一瞬で終わります)
7. バックアップの保護もありますが、不要ならチェックを外してください。(安全のため、初期状態ではチェックが入っています。)
8. １つの譜面に情報が入っている場合は、読み込んだ時点で基本情報に自動で入力される逆引きもできます。
9. このプログラムは、あくまで曲情報を書き換えるだけのものであり、譜面データへは一切の手を加えません。
10. 以上のことから、Base16、Base36、Base62の拡張定義において全てお使いいただけます。
